# Traffic Signal City – OpenGL

A 2D city simulation developed using C++ and OpenGL/GLUT, featuring animated vehicles, traffic lights, day and night modes, and interactive scene elements.

## Features

- 2D city environment
- Animated cars and vehicles
- Traffic signal system
- Day and night scene modes
- Interactive elements
- 2D geometric shapes for scene construction
- OpenGL transformations and animation

## Technologies

- C++
- OpenGL
- GLUT
- 2D Computer Graphics

## Project Type

Academic / University Project

## Description

This project demonstrates the use of OpenGL and C++ to create an animated 2D city environment. The scene combines geometric shapes, transformations, colors, and animation techniques to simulate vehicles and traffic signals within a city setting.
